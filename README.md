# salmansadiq.com

Portfolio of Salman Sadiq — Graphic Designer & QA Engineer.

Built with Next.js 16 (App Router), Motion and Lenis. Deployed on Vercel.

```bash
npm install
npm run dev     # http://localhost:3000
npm run build
```

## Editing content

- **Projects & catalog** — `src/data/projects.ts` (text) and `public/work/<project>/` (images, listed in `src/data/images.json`).
- **Profile, experience, skills, QA products, Behance link** — `src/data/profile.ts`.
